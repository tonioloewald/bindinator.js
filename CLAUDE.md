# CLAUDE.md

Guidance for working in this repository (bindinator / **b8r**, "the even lazier
javascript framework"). Reactive, no-build, vanilla-JS front-end framework using
data-binding via DOM attributes and a path-based registry.

## Commands

- `npm start` — serve the site locally at `http://localhost:8017/index.html`
  (runs `node utils/server.js web_root:.`). The docs site **is** the app.
- `npm run lint` — `standard --fix` (JavaScript Standard Style; no semicolons,
  2-space indent, single quotes).
- `npm run stylelint` — stylelint over `css/*.css` and HTML.
- `npm run linthtml` — linthtml over `index.html` and `components/**/*.html`.
- `npm run build` — lint + stylelint + linthtml, then `./utils/build.command`
  (rollup, see `rollup.config.js`) which bundles `source/` into `dist/b8r.js`.

There is no headless test runner. Tests are **literate/browser-based**: open
`test/unit-tests.html` in a browser. Inline tests live in `~~~~ … ~~~~` fences
inside source-file doc comments (see `source/component.js` for examples) and are
executed by the documentation/test system.

## Layout

- `source/` — the framework source (ES modules). Entry/orchestrator is
  `source/b8r.js`. Bundled into `dist/b8r.js` for distribution.
- `components/` — UI components. **Two kinds coexist:**
  - **Legacy v1**: `*.component.html` (`<style>` + markup + `<script>`). The
    script body is wrapped in an `AsyncFunction` by `makeComponent` and receives
    `(component, b8r, find, findOne, data, register, get, set, on, touch)`.
  - **New v2**: `*.component.js` / plain `*.js` — `export default { css, view|html,
    initialValue, load, type }`, built by `makeComponentNoEval`. v2 `load`
    receives a destructured object `{ component, b8r, data, find, findOne, get,
    set, on, touch }` and **does not** get `register`.
- `web-components/` — custom elements (`makeWebComponent`), e.g. `code-editor.js`,
  `tabs.js`.
- `lib/`, `third-party/`, `services/`, `utils/` — helpers, vendored deps,
  data services, and the dev server / build script.
- `docs/`, `documentation.json`, `README.md` — the documentation site config.

## Component system (key files)

- `source/component.js` — `component()` (loads by url; `.js` → `import()`,
  otherwise ajax `*.component.html`), `makeComponent()` (v1 HTML path, uses
  `AsyncFunction`), `makeComponentNoEval()` (v2 object path). `_component_` in a
  component's css/markup is rewritten to `<name>-component`.
- `source/b8r.js` — defines the `<b8r-component>` custom element
  (`name`/`path` attributes; `path` calls `b8r.component(name, path)`),
  `insertComponent`, `wrapWithComponent`, `componentOnce`.
- Relative `import()`/paths inside a component resolve **relative to the
  document base URL** (the served page), not the component file — components are
  authored with `../lib/…`, `../source/…`, `../components/…` accordingly.

## Component editor (current task area)

- `components/component-editor.js` — v2 component that edits a component's
  docs/css/html/js and live-previews it. `loadSource()` parses legacy
  `*.component.html` into `{docs, css, html, js}`, wrapping the `<script>` body
  into a v2 `async load({…})`. `getSource()` reassembles a v2 module;
  `reload()` POSTs that module to `/vfs/ce-<uuid>.js` and `import()`s it.
- `components/component-viewer.component.html` — loads a component's source
  (`b8r.component(url, undefined, true)` preserves `_source`) and feeds it to the
  editor's `loadSource()`.
- `vfs.js` / `vfs.worker.js` — a **service-worker virtual file system** at
  `/vfs/`, used so reconstructed components can be `import()`ed "as if real".
  Caveats (per `vfs.js` docs): service workers don't work on first page load (it
  force-reloads), updates aren't forced, and the round-trip is fragile —
  this is the weak point behind "legacy components with dependencies don't work
  in the new editor."

## Conventions

- JavaScript Standard Style (run `npm run lint` before committing).
- Logging uses `console.debug('b8r-error'|'b8r-warn', …)` rather than raw
  `console.error`/`warn`.
- Don't hand-edit `dist/` — it's generated by `npm run build`.
